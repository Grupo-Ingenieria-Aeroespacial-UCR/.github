# Grupo de Ingeniería Aeroespacial — UCR 🚀

Somos un grupo estudiantil de la Universidad de Costa Rica dedicado al diseño, construcción y lanzamiento de cohetes y satélites experimentales (CanSats). Participamos en competencias internacionales como **ARLISS** y desarrollamos proyectos propios como **CRATER**.

---

## 🛰️ Proyectos principales

### CRATER
Proyecto de CanSat y cohete del grupo. Incluye diseño de hardware, firmware embebido y misión científica.

- 📂 [CRATER-TALLER-PROGRA](https://github.com/Grupo-Ingenieria-Aeroespacial-UCR/CRATER-TALLER-PROGRA) — Taller de programación del proyecto CRATER (C++)
- 🔒 [CRATER-General](https://github.com/Grupo-Ingenieria-Aeroespacial-UCR/CRATER-General) — Documentación general e IREC
- 🔒 [CRATER-Miravalles](https://github.com/Grupo-Ingenieria-Aeroespacial-UCR/CRATER-Miravalles) — Cohete Open Class con motor K para lanzamientos tipo ARLISS (Python)
- 🔒 [CRATER-Estacion-Banco-Pruebas](https://github.com/Grupo-Ingenieria-Aeroespacial-UCR/CRATER-Estacion-Banco-Pruebas) — Código del banco de pruebas (C++)
